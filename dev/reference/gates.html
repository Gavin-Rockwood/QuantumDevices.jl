Pulses, gates, and calibration ​

Timed controls and envelopes ​

QuantumDevices.AbstractPulse Type

Common interface for timed scalar controls, including Pulse and PulseSequence.

QuantumDevices.Pulse Type
julia
Pulse(envelope; duration, amplitude=1, offset=0, delay=0)
Pulse(envelope, frequency::Number; duration, amplitude=1, offset=0,
      delay=0, phase=0, reference=:pulse)

Envelopes use physical pulse-local time. Active values include the full offset; outside the closed pulse window the value is offset. A positional frequency mixes I+iQ as I_cos(θ)-Q_sin(θ). reference=:sequence uses time from the immediately enclosing sequence's onset, including child delay; standalone it uses input time. EnvelopeSequence duration is inferred and cannot be stretched.

QuantumDevices.PulseSequence Type
julia
PulseSequence(pulses...; offset=0, delay=0)

Sequential controls. First child delay is measured from sequence onset; each subsequent delay is a gap after the previous child. Gaps return sequence offset; active children supply their full value. Outer delay places the whole sequence. Internal boundaries belong to the following child, except the final endpoint.

QuantumDevices.pulse_tstops Function
julia
pulse_tstops(control)

Return sorted unique physical control boundaries, joins and interpolation knots, including delay and nested sequence placement. Supply these times to an integrator.

QuantumDevices.AbstractEnvelope Type
julia
AbstractEnvelope

Reusable dimensionless shape evaluated by envelope_value(shape, t, duration). Time is relative to pulse onset. Implement that method for custom subtypes; optionally implement validate_envelope(shape, duration) and persistence hooks.

QuantumDevices.Envelope Type

Normalized shape with a physical reference duration and optional region metadata.

QuantumDevices.EnvelopeSequence Type

Concatenated shape pieces; duration is the checked sum and cannot be stretched as a whole.

QuantumDevices.Segment Type

A shape piece with inferred/explicit duration and finite real or complex scale.

QuantumDevices.InterpolatedEnvelope Type
julia
InterpolatedEnvelope(times,values;duration,interpolation=:linear)

Linear real/complex samples from physical time zero to duration. Input nodes normalize once; duration-only changes stretch nodes. Physical times/values paths rebuild atomically.

QuantumDevices.envelope_tstops Function

envelope_tstops(shape::AbstractEnvelope, duration)

Interior pulse-local times at which adaptive integration should stop. Defaults to no stops. Custom envelopes can implement this for joins or discontinuities; pulse_tstops adds pulse boundaries and shifts these times by the pulse delay.

Gate preparation and evolution ​

QuantumDevices.Control Type

Bind a named pulse's full value to a Hamiltonian parameter (including its offset).

QuantumDevices.GateRecipe Type
julia
GateRecipe(model_recipe; controls=[], terms=[], duration=nothing, metadata=(;))

A physical gate definition with numerical pulses and optional model-reference offsets. An omitted duration follows the latest control endpoint; an explicit duration remains fixed, including when it initially equals that endpoint. Optimization variables and pulse links belong to CalibrationProblem.

QuantumDevices.PreparedGate Type

Captured gate provenance and its fixed reference model; no upstream models are retained.

QuantumDevices.check_endpoints Function

Explicitly require controlled values at 0 and duration to match reference values.

QuantumDevices.GateEvolution Type

Physical lab-frame evolution in the reference model's construction coordinates. inputs === nothing denotes full identity propagation; otherwise inputs are ordered orthonormal kets. times are elapsed times and always include the final gate duration. Propagators retain leakage and all relative physical phases, with an explicitly selected vacuum energy origin recorded in solver metadata.

Reference arrays and provenance are captured independently of the prepared model. As for GateRecipe, arbitrary mutable state hidden inside user closures is outside snapshot guarantees. Arrays and QuantumObjects retain ordinary mutable behavior.

QuantumDevices.evolve Function
julia
evolve(prepared::PreparedGate; states=nothing, saveat=nothing, remove_vacuum=false, energy_shift=0, kwargs...)

Evolve the full retained Hamiltonian using 2π * make_hamiltonian(prepared) and QuantumToolbox.sesolve. Default propagation is the full identity, saved only at completion. states selects ordered occupation labels (reference eigenstates) or orthonormal QuantumObject kets. saveat requests elapsed-time history; the final time is appended if necessary. energy_shift is a constant offset in GHz (or :auto for the mean reference energy of the input columns). It is subtracted only during integration; every saved propagator has that centering phase restored. remove_vacuum=true instead leaves the fixed reference vacuum energy subtracted from the returned evolution, as in make_hamiltonian. Automatic centering is relative to that selected energy origin. The solver metadata records both choices; neither flag reaches the native ODE solver. Native solver keywords pass through. Pulse stops are merged with user tstops. Unsuccessful integration throws an error.

Saving must preserve all retained rows/columns: save_idxs, e_ops, and save_end=false are unsupported. Stored propagators retain all relative physical phases and the explicitly selected global energy origin. Reference idle_phases diagnostics keep the original reference energies; result.solver.vacuum_energy records the removed global offset.

Evolve the current working recipe; use evolve(gate.calibration) for captured replay.

QuantumDevices.unitary Function

Return a physical full-space propagator. Selected-column results have no unitary.

QuantumDevices.idle_phases Function

Unwrapped reference idle phases 2π E t; idle evolution is exp(-im*phase).

QuantumDevices.gate_matrix Function
julia
gate_matrix(result; states=nothing, output_states=nothing, step=...)

Project physical evolution onto ordered orthonormal bases, preserving leakage. For a full propagator, states selects input kets/labels (energy-ordered reference eigenstates by default), and output states default to inputs. Selected-column propagation keeps its recorded input order, rejects states, and defaults outputs to stored inputs. Distinct output bases may have a different number of states. All physical dynamical phases are retained; projection applies no reference-Hamiltonian inverse or phase compensation.

Calibration ​

QuantumDevices.calibration_parameters Function

Discover numeric candidates and symbolic offset references; excludes Boolean and sample-count configuration. Symbolic references are not numeric optimizer variables.

Physical pulse fields keyed by control_name/pulse/path; derived durations are excluded.

QuantumDevices.CalibrationProblem Type
julia
CalibrationProblem(result; kwargs...)
CalibrationProblem(result, paths, target=result.target; kwargs...)

Warm-start from the captured candidate without rebuilding its physical model. Evolution settings merge with the original solve settings; explicit function_kwargs replace derivative hooks. Explicit paths or mapping declarations require explicit lb, ub, and function_kwargs, and reset integrality/constraint bounds.

QuantumDevices.CalibrationResult Type

A candidate recipe and ordered target basis captured from a calibration solve. solution is the untouched native optimizer result. Ordered coordinates, owned fitted_values and parameterization retain the optimization family; paths lists actual written physical fields and need not have the coordinate count. validation is nothing until explicitly reevaluated. Arrays remain ordinary owned data; user callables may retain external mutable state.

QuantumDevices.calibrated_recipe Function
julia
calibrated_recipe(problem::CalibrationProblem, values)

Materialize a concrete GateRecipe from coordinates in optimizer order. Resolve all links and rebuild affected pulse fields atomically; do not optimize, evolve or mutate problem snapshots. Invalid coordinates or pulse geometry throw before returning.

QuantumDevices.validate_calibration Function
julia
validate_calibration(result; evolution_settings=(;), save_evolution=false)

Perform one explicit reevaluation with the captured target/input order. Return a new result with validation.loss, its effective settings, and optional saved evolution. The optimizer-reported objective and original result are unchanged.

QuantumDevices.QuantumGate Type

A working gate recipe and at most one independently captured calibration result.

QuantumDevices.gate_infidelity Function
julia
gate_infidelity(target, actual)

One minus average pure-state target overlap, including loss from the selected subspace: 1 - (tr(M'M) + abs2(tr(T'M)))/(d*(d+1)). The target T is unitary; M may leak and is never renormalized. Relative phases count, global phase does not.

CommonSolve.solve Function
julia
solve(problem::CalibrationProblem[, algorithm]; kwargs...)

Return a CalibrationResult with the untouched native optimizer solution. Without an algorithm, use NLopt's bound-aware LN_NELDERMEAD; its maxiters limits objective evaluations. Explicit algorithms retain their native SciML keyword semantics. No additional evolution or coordinate transformation is performed.

solve(problem; kwargs...) uses the default bound-aware NLopt Nelder–Mead backend. solve(problem, algorithm; kwargs...) selects a native SciML optimizer and returns CalibrationResult; solving problem.problem returns the native solution.
