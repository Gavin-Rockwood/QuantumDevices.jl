QuantumDevices.make_transmon Function
julia
make_transmon(name::Symbol, EC, EJ; ng=0.0, dimension=101, label=missing, metadata=(;), subscript=missing)
make_transmon(name::Symbol; EC, EJ, kwargs...)
make_transmon(; name, EC, EJ, kwargs...)

Construct the symbolic charge-basis Hamiltonian 4EC*(charge-ng)^2 - EJ*jump/2. EC and EJ use frequency units E/h; ng is dimensionless offset charge. The charge and jump operator generators return QuantumToolbox operators, with charge states -ncut:ncut and nearest-neighbor tunneling respectively. dimension = 2*ncut + 1 is a positive odd state count, defaulting to 101. No operators are generated or diagonalized until a numerical model is built. Increase the charge dimension to check convergence of retained energy levels.

QuantumDevices.make_flux_tunable_transmon Function
julia
make_flux_tunable_transmon(name::Symbol, EC, EJmax;
    d=0.0, ng=0.0, flux=0.0, dimension=101, label=missing, metadata=(;), subscript=missing)
make_flux_tunable_transmon(name::Symbol; EC, EJmax, kwargs...)
make_flux_tunable_transmon(; name, EC, EJmax, kwargs...)

Construct a split-junction transmon with effective Josephson energy EJmax * sqrt(cospi(flux)^2 + d^2*sinpi(flux)^2). flux is external flux Φext/Φ0, and d is junction asymmetry. All five physical inputs remain independent symbolic parameters. Charge-basis generators, dimensions, and energy units follow make_transmon.

QuantumDevices.NumericalModel Type

An ephemeral construction-basis capture of a persistent recipe.

H is the stored reference QuantumObject, assembled and cleaned once at build using the default numerical cleanup threshold. Operators, complete products, and energy-ordered eigenstates share its coordinates. Explicit downstream projection creates a new basis. Arrays retain ordinary mutability; H is an independent captured reference, not a live view recomputed after cache mutations.

QuantumDevices.build Function
julia
build(device, recipe; parameters=Dict(), dressed_threads=nothing, tracking_threads=missing)

Build a fresh construction-basis model. Operators, numerical Hamiltonians, and exposed eigenstates share coordinates; diagonalization supplies spectra/labels without rotating operators. Explicit selections create new bases from upstream eigenvectors. Eigensystems remain eager except pure reductions, which inherit them without a new solve. Explicit parameters override all recipe values. tracking_threads=missing inherits each node’s effective dressed worker count; an explicit positive Int overrides tracking independently. dressed_threads overrides the sample worker count for every dressed node in this build. It must be a positive Int, or nothing to honor each recipe's dressing_options.thread_count. Workers are capped by available default-pool threads and sample count. This execution setting does not alter recipe provenance.

julia
build(device, gate; parameters=Dict(), dressed_threads=nothing, tracking_threads=missing)

Capture a gate and project complete operator products in its ordinary model basis. dressed_threads and tracking_threads have the same per-build meaning as for model recipes. Added terms do not affect reference diagonalization, energies, or state labels. Recipe/control/term containers and physical component/interaction definitions are captured independently for calibration provenance. Arbitrary callable captured external state remains outside the snapshot boundary.

Build the current working recipe, independently of the calibrated snapshot.

QuantumDevices.stateenergy Function

Return the energy (E/h) associated with a complete occupation tuple.

get_hamiltonian(device, recipe) and get_hamiltonian(model) return the physical symbolic Hamiltonian; make_hamiltonian(model[, free_parameters]), make_hamiltonian(prepared), and make_hamiltonian(model, gate) return a QuantumObject or QobjEvo. With remove_vacuum=true, these numerical overloads subtract the model's fixed reference all-zero occupation energy times identity before scalar scaling. Untracked models use their lowest reference eigenenergy; tracked reductions missing the vacuum label throw. This is a constant global energy-origin choice, not an instantaneous ground-state calculation or reference-Hamiltonian inverse. Stored model.H and caches remain unchanged, and evolution/calibration defaults retain physical phases.

model.H is the stored numerical reference. get_hamiltonian is symbolic; use make_hamiltonian to copy, compile, scale, or shift a numerical Hamiltonian.
