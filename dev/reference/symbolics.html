Symbolics and evaluation ​

Scalar variables and expressions use Symbolics.jl directly. Quantum expressions retain their owner-aware noncommutative operator references.

QuantumDevices.component_parameters Function
julia
component_parameters(name; subscript=missing, EC=.25, EJ=18.)

Return (variables, parameters): local aliases to owned Symbolics variables and a matching string-keyed idle-value dictionary. subscript=missing uses alias_component (for example EC_q1), nothing leaves aliases unsuffixed, and a nonempty Symbol or string supplies an explicit suffix. Recreating equal names produces equal variables, including intentionally shared variables. Idle values remain authoritative in the returned dictionary.

QuantumDevices.component_operators Function

Return symbolic operators and their factories as matching string-keyed maps.

QuantumDevices.Interaction Type

A coupling with all used variables and optional explicitly declared defaults.

String declaration keys must be the full symbolic name and map to (variable, value). Atomic symbolic keys may map directly to values. Variables retain their identities.

QuantumDevices.Sym Type

An owner-aware symbolic arithmetic tree for Hamiltonians.

QuantumDevices.OperatorRef Type

An operator identity given by component owner and local operator name.

QuantumDevices.op Function

Reference a local operator belonging to owner.

QuantumDevices.val Function

Insert a numerical constant into a symbolic expression.

QuantumDevices.evaluate Function

Evaluate a symbolic tree using parameter and owner-aware operator dictionaries.

QuantumDevices.latex Function
julia
latex(object; labels=Dict())

Return notebook mathematics without altering symbolic identities. Label keys are Symbolics variables, OperatorRef, or bound operator identities; LaTeXString values are raw math, while ordinary strings are escaped labels. Bound operators also accept a physical OperatorRef fallback. Input annotations are omitted when the alias equals the physical owner.

QuantumDevices.make_hamiltonian Function
julia
make_hamiltonian(model; auto_time_dependence=true, scalar=1, remove_vacuum=false, herm_check=1e-9)
make_hamiltonian(model, free_parameters; auto_time_dependence=true, scalar=1, remove_vacuum=false, herm_check=1e-9)

Convert the physical Hamiltonian in the model's fixed construction basis. With no free parameters (including an empty collection), return a static QuantumToolbox QuantumObject. A nonempty collection of Symbolics variables returns a QobjEvo. Free parameters are a positional argument, not a keyword. The default static conversion copies stored model.H, assembled and cleaned once at build. Custom scalar or herm_check conversions recompile raw cached products so their cleanup threshold applies after scaling. Mutating caches does not rebuild the stored H; rebuild the model after changing captured reference data.

Designated parameters read runtime values using p[variable](t), or p[variable] when auto_time_dependence=false. All other parameters retain their resolved build values. Neither the basis nor truncations change. auto_time_dependence has no effect on static conversions. scalar and fixed multiplicative coefficient factors are folded into fresh operator matrices once; runtime callbacks evaluate only residual expressions. Fixed denominators and signs are extracted, while additive and nonlinear structure stays inside callbacks. Set scalar=2pi to return angular-frequency Hamiltonians. For each final scaled fixed operator matrix O, use 0.5*(O + O') when norm(O - O') < herm_check (QuantumToolbox's trace norm for operators). Static conversion checks the assembled Hamiltonian once. Dynamic conversion checks its accumulated constant and each free-parameter term's fixed operator matrix at construction, never at runtime. Complex runtime coefficients can still make the full Hamiltonian non-Hermitian. Cached model operators are unchanged. The absolute threshold must be a finite nonnegative real number; herm_check=0 disables cleanup. remove_vacuum=true subtracts the reference all-zero occupation state's energy as a constant identity term at every time, before scalar scaling. If labels are unavailable, the lowest reference eigenenergy is used. A tracked model missing its vacuum label throws. This changes only the global energy origin, does not track the instantaneous ground state, and leaves model.H and caches unchanged. The default scalar=1 preserves E/h units. Gate evolution applies its own single 2π conversion. Complex scaling is retained: cleanup never symmetrizes a scaled matrix whose Hermiticity defect exceeds the threshold.

julia
make_hamiltonian(prepared; scalar=1, remove_vacuum=false, herm_check=1e-9)

Compile the captured Hamiltonian, preserving E/h units with the default scalar=1. Use scalar=2pi for angular-frequency units. The scalar and fixed coefficient factors are folded into new matrices before herm_check cleanup. Returns a QuantumObject without controls, otherwise QobjEvo. Controlled scalar coefficients call the captured pulses at runtime; runtime p is ignored. All uncontrolled parameters keep their resolved build values. Fixed matrices and scalar expression structure are compiled once. remove_vacuum=true uses the captured model's constant reference vacuum energy; added gate terms and pulse values do not redefine that reference. Coefficients retain explicit adjoint terms; hermiticity cleanup follows make_hamiltonian(model).

julia
make_hamiltonian(model::NumericalModel, gate::GateRecipe; scalar=1, remove_vacuum=false, herm_check=1e-9)

Compile a gate against a compatible captured model using only cached complete operator products. No model is built. Concrete recipe trees must agree in basis choices and effective explicit reference assignments; omitted assignments inherit model.parameters. Controls may replace those reference values at runtime. Missing products require an explicit rebuild with the gate terms. scalar and fixed coefficient factors are folded into fresh matrices before herm_check, with the same units and cleanup semantics as make_hamiltonian(model).

Compile the current working recipe against a compatible captured physical model.

QuantumDevices.get_hamiltonian Function

Return the original physical symbolic Hamiltonian without numerical construction. Dependency and selection validation still applies; numerical max_dimension caps are enforced by build, so oversized recipes can be inspected before refinement.

Retrieve the model's physical symbolic Hamiltonian; numerical reference data remains in .H.
