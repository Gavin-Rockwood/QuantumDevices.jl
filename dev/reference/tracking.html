Tracking and parameter paths ​

QuantumDevices.track_states Function
julia
track_states(state_history; seed=nothing, seed_transport=nothing, keys=nothing,
             other=(;), save_steps=:all,
             transports=nothing, method=:quick, degeneracy_atol=1e-9,
             degeneracy_rtol=1e-10, overlap_threshold=0.5, tracking_threads=1)

Follow normalized kets with one-to-one assignment and phase alignment. The default method=:quick takes each reference's best still-available candidate in reference order, breaking ties by candidate order. method=:global maximizes total squared overlap across all references. Inputs share coordinates unless explicit QuantumObject transports map between consecutive bases; projected reference norm loss is retained. Auxiliary other histories follow the same assignments; optional finite real energies provide degeneracy diagnostics. Keys default to (0,), (1,), ....

An optional normalized seed supplies a separate step-zero reference collection. Only its m trajectories are followed through each candidate sample (which may have more states). Match seed to the first sample, then each matched, phase-aligned collection to the next. Keys match the seed count. seed_transport maps seed coordinates into the first sample; otherwise their bases must agree. It requires seed and is separate from the consecutive-sample transports. The seed is outside the saved history: save_steps=[1] denotes the first supplied sample, total_steps excludes the seed, and auxiliary histories need no seed entry. First-sample overlap accuracy includes seed matching, including projected norm loss.

Process every sample, retaining only save_steps. Multiple saved samples have key rows and sample columns; one saved sample produces vectors. Accuracy is saved at those samples; final diagnostics always summarize the entire processed path. These are continuity diagnostics, not probabilities of correct labeling. tracking_threads bounds default-pool overlap workers. Parallel execution caches bounded windows of dense adjacent overlaps; matching and phase alignment remain ordered. One worker retains the direct, allocation-light quick matcher without a seed. Seeded transitions remain sequential and compute rectangular m-by-n overlaps; workers share candidate-column batches within each transition, with task-owned packing scratch and deterministic assignment/phase alignment.

QuantumDevices.TrackingResult Type

Shared owner for tracked arrays, saved samples, keys, and full-path diagnostics.

QuantumDevices.TrackedData Type

Tracked vector or matrix with an immutable container and ordinary array contents. Normal indexing/slices use ordinary one-based array semantics. Calling with a key returns its row history, or a scalar for a single saved sample. data.tracking is the shared owner. Slices/copies/broadcasts are ordinary independent arrays. No assignment forwarding or custom mutation protection is provided; array and QuantumObject contents retain their usual behavior.

QuantumDevices.LabelDiagnostic Type

Path diagnostics; overlap measures are not probabilities of correct labeling.

QuantumDevices.DressedStates Type

Final energy-ordered construction-basis states and energies with physical tuple order.

QuantumDevices.parameters Function

All explicit pulse fields as slash paths and (path,value) pairs, including structural choices.

QuantumDevices.getpath Function
julia
getpath(object, path::AbstractString)

Read a nonempty slash-separated path through structs, named tuples, dictionaries, arrays, or tuples. Array indices are one-based. A struct's parameters may omit the parameters/ segment when no field shadows that name. Dictionary segments match symbol, string, or integer keys; ambiguous matches throw ArgumentError. Missing keys throw KeyError.

julia
julia> getpath((drive=(amplitude=0.2,),), "drive/amplitude")
0.2
QuantumDevices.haspath Function
julia
haspath(object, path::AbstractString)

Return whether a path resolves using getpath rules. Missing keys return false; malformed or ambiguous paths still throw rather than hiding the error.

QuantumDevices.setpath Function
julia
setpath(object, path::AbstractString, value)

Return an updated object by copying containers along the path and reconstructing structs. Unchanged branches may be shared; the original is not modified.

julia
julia> setpath((amplitude=0.2,), "amplitude", 0.4)
(amplitude = 0.4,)
