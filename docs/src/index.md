QuantumDevices uses QuantumToolbox for quantum operators and evolution, and SciML
for optimization. Start with the [quickstart](getting_started/quickstart.md), then
follow the [model guide](user_guide/models.md) and [calibration tutorial](user_guide/calibration.md).


Work through [gate evolution and trajectories](user_guide/gates.md), then apply
the workflow in the [transmon–resonator](tutorials/transmon_resonator_control.md)
and [tunable-coupler](tutorials/tunable_coupler_control.md) tutorials. Their full
numerical source is runnable explicitly; documentation builds execute only small
illustrations, not the expensive calibrations.
